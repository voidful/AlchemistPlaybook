How the skill works.

The skill first collects the facts about your run: task type, model, data, hardware, symptom, and config. A routing table then points to one evidence file for each topic. The script scripts/estimate.py does all the arithmetic. Each answer has four parts: Diagnosis, Recipe, Evidence, and Verify. The Recipe is a config diff. Each change has a citation and a rollback plan. For tracked experiments, the skill also makes an HTML report, one git commit for each change, and a GitHub Pages URL. This page obeys the same rule.

Cross-stage learning-rate ladder

The peak learning rate decreases approximately 10 times at each stage. If your SFT learning rate is not less than your pretrain learning rate, that is the bug. The dots show published values. Move the pointer over a dot to see its source.
